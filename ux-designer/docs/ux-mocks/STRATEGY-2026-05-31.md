# Product Strategy Notes — 2026-05-31

Four themes for evolving Rufkis from a dashboard into an autonomous SRE platform.

## 1. GitOps-Native Remediation

**Current gap:** AI Chat, Pod Diagnostics, and Workload Builder output applies YAML directly (`App.ApplyYaml`), bypassing the declarative source of truth.

**Target:** When the AI diagnoses a CrashLoopBackOff or suggests a traffic split, offer **"Create PR"** instead of "Deploy". SREs approve AI-generated fixes in their standard GitHub workflow; Argo CD handles sync.

**Affects:** monitoring/rufkisai, workload builder → operations/pipelines, operations/rufkiscd (Argo CD integration)

## 2. Automated FinOps ROI

**Current gap:** Waste Heatmap (monitoring/waste) and Cost Explorer (monitoring/finops) identify waste but require human action to fix.

**Target:** Surfacing actionable "Right-size Deployment-X to save $400/mo → [Generate PR]" cards. Connects to Workload Builder + pipelines for auto-remediation.

**Why:** Customers easily justify platform cost when it provably pays for itself.

## 3. Autonomous Agents (Sub-Agent Layer)

**Current gap:** AI is primarily reactive (chat, alert diagnosis). Foundational MCP layer and Agent CRD (agents/my-agents) exists but unused for autonomous behavior.

**Target:** Background "watcher" agents that correlate monitoring/anomalies with recent Argo CD syncs and k8s events. When Anomstack fires, the agent has already pulled logs, checked PR guidelines, cross-referenced Markdown runbooks (operations/runbooks), and placed a root-cause summary in the incident tracker before the SRE is paged.

**Why:** Shifts product from "tool the SRE uses to investigate" to "active teammate that completes first 15 minutes of triage."

## 4. Deepened Local-First SRE Workspace

**Current gap:** Wails desktop + Vue 3 with biometric auth, Tailscale/mesh, local shell — unique differentiator, but pieces aren't wired together.

**Target:** Bind terminal drawer to evernote/knowledge. Allow Markdown runbooks with executable blocks. Clicking a block executes in Wails pseudoterminal, pipes ANSI output through AI copilot for validation. Local knowledge management + secure execution + AI explanation in a single keyboard-driven flow.

**Why:** Context switching is the enemy of incident response. Platform becomes sticky when SREs never leave it.

## Cross-Cutting Observations

- All four themes share a **GitOps bridge** — the workflow is "Rufkis detects → generates PR → SRE approves → Argo CD syncs"
- The **Agent CRD + MCP layer** in agents/my-agents is the right abstraction point for autonomous sub-agents
- **Local Markdown runbooks** (operations/runbooks) are a content anchor for both terminal execution and AI context
- **ROI visibility** (FinOps) and **time-to-value** (autonomous triage) are the two strongest enterprise sales arguments
